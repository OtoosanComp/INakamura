# Lista para la primera prueba real (cosplay)

## Antes del evento (con internet)
- [ ] La app está publicada (GitHub Pages) y abre en `https://otoosancomp.github.io/INakamura/`.
- [ ] En el Redmi Note: Chrome → abrir la dirección → ⋮ → **Instalar app**.
- [ ] Configurar: nombre visible, modos, CLABE real (debe decir "✓ CLABE válida"), titular y WhatsApp.
- [ ] Ajustes → Demostración → **Borrar datos de demostración** (si los cargaste).
- [ ] Registrar 3 productos (o más) con precio y existencias.
- [ ] **Modo avión** en el teléfono → abrir la app → crear una venta → debe generar el QR igual.

## Prueba con dos teléfonos
1. [ ] Crear una venta con 2 productos distintos. Verificar el total.
2. [ ] Anotar el folio (p. ej. `A-0001`).
3. [ ] Con **otro teléfono** (Android y, si se puede, iPhone): escanear con la cámara.
4. [ ] Se abre el ticket: artículos, precios, total y nombre correctos.
5. [ ] **Copiar CLABE** → pegar en la app del banco → aparece el titular correcto.
6. [ ] **Copiar importe** → pegar en el monto.
7. [ ] **Copiar concepto** → pegar (el banco lo acepta sin acentos).
8. [ ] Hacer una transferencia real pequeña (p. ej. $1) y ver que llegue con el folio en el concepto.
9. [ ] "Ya pagué · Enviar comprobante por WhatsApp" abre el chat correcto.
10. [ ] "Guardar ticket (imagen)" crea la imagen.
11. [ ] En la app: **Ya pagó** → la venta pasa a Pagado.
12. [ ] Ventas → el resumen del día cuadra. Buscar por folio y por producto.
13. [ ] Probar "¿No le abre la página? Mostrar QR solo con CLABE".
14. [ ] Probar el modo oscuro +18 con el concepto anónimo y los artículos ocultos.

## Después del evento
- [ ] Ajustes → Respaldo → **Descargar**, y guardarlo en un lugar privado.
- [ ] Anotar qué fue lento, confuso o faltó: eso define la v0.2.
